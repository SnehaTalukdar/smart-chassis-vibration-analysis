## SMART CHASSIS VIBRATION ANALYSIS SYSTEM ##

# PROJECT OVERVIEW:
A machine-learning-based system for analyzing vehicle chassis vibrations and classifying them into Normal, Warning, and Critical conditions.

# TECHNOLOGIES:
-> Python
-> Google Colab
-> Pandas
-> NumPy
-> Matplotlib
-> Scikit-learn

# FEATURES:
-> Acceleration
-> Frequenct
-> RMS Vibration

# MACHINE LEARNING:
Machine learning models are trained and evaluated to classify different chassis vibration conditions.
